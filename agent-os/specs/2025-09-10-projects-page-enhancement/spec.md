# Spec Requirements Document

> Spec: Projects Page Enhancement
> Created: 2025-09-10

## Overview

Enhance the projects page design and content to match the home page's improved visual hierarchy, container structure, and component patterns. This update will create a more cohesive user experience by copying project content from the home page and applying consistent styling throughout.

## User Stories

### Site Visitor Views Projects

As a site visitor, I want to browse Joey's current and past projects in a visually appealing and well-organized page, so that I can understand his expertise and track record.

The visitor lands on the projects page and sees a consistent container structure matching other pages. They first encounter currently building projects displayed in attractive cards with proper visual hierarchy. As they scroll, they discover past work organized by category with improved styling. The proven track record section reinforces credibility with metrics and testimonials, similar to the home page experience.

### Potential Client Evaluates Expertise  

As a potential client, I want to see a comprehensive overview of Joey's project portfolio and achievements, so that I can assess whether his skills match my needs.

The client navigates to the projects page and finds current projects prominently displayed with clear descriptions and technology stacks. They review past work categorized by company and type, making it easy to identify relevant experience. The proven track record section with metrics and testimonials provides social proof and credibility indicators that help inform their hiring decision.

## Spec Scope

1. **Container Consistency** - Apply the same container structure and styling patterns used on the home page to the projects page for visual cohesion
2. **Project Content Migration** - Copy current projects content from the home page component, removing the Invoice → Xero Automation project
3. **Past Work Styling** - Redesign the past work section with improved visual hierarchy and card-based layout for better readability
4. **Proven Record Integration** - Include the proven track record section from the home page to showcase metrics and testimonials on the projects page
5. **Design Polish** - Apply minor design and copywriting improvements to enhance overall page quality and user experience

## Out of Scope

- Creating new project content or case studies
- Building interactive project filtering or search functionality
- Adding project detail pages or modal views
- Implementing contact forms or lead capture beyond existing CTAs
- Database integration for dynamic project management

## Expected Deliverable

1. Projects page displays with consistent container structure matching other site pages, verified by visual inspection in browser
2. Current projects section shows the same content as home page (minus Xero project), with proper card layout and styling confirmed working
3. Past work section renders with improved visual design and the proven track record section displays correctly with metrics and testimonials
