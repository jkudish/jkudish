## [Open source](https://jkudish.com/open-source)

- **[Jev Browser](https://github.com/jkudish/jev-browser)**: Fast and very cheap agentic browser-use with TypeSafe's Jev model.
- **[Jev MCP](https://github.com/jkudish/jev-mcp)**: Fast, cheap, typed judgments from TypeSafe's Jev model, as MCP tools. Give your agents improved, super fast and cheap judgment tools.
- **[Jev Agent Tools](https://github.com/jkudish/jev-agent-tools)**: Jev transport/provider layer: multi-provider transport with fail-closed validation, used by Jev Browser and Jev MCP.
- **[librarium](https://github.com/jkudish/librarium)**: Give your agent more than one source. Use librarium to query search engines, check AI answers, and deep-research APIs. Review the results and citations together, without building a separate integration for every provider.
- **[Laravel AI Pricing](https://github.com/jkudish/laravel-ai-pricing)**: Track what AI calls cost in your Laravel app, with traceable pricing, cost attribution, and estimates.
- **[Laravel Document Extraction](https://github.com/jkudish/laravel-document-extraction)**: Scan any document with Laravel. Extract text and structured data, with provenance and AI cost tracking built in.
- **[Pest AI Benchmarks](https://github.com/jkudish/pest-plugin-ai-benchmarks)**: Compare models, prompts, and AI configurations in Laravel to find the best balance of performance and cost for your AI integrations.
- **[MailMirror](https://github.com/jkudish/mail-mirror)**: Securely sync your emails into Laravel. Works with Gmail and any JMAP-compatible inbox such as Fastmail.
- **[Conduit](https://github.com/jkudish/conduit)**: A proxy to use your existing coding agent subscriptions with the Laravel AI SDK.
- **[Plume](https://github.com/jkudish/plume)**: Laravel SDK client for the [X.com](https://x.com/jkudish) API v2.
- **[Graft](https://github.com/jkudish/graft)**: The missing Git and GitHub integration for Laravel.
