# Spec Requirements Document

> Spec: Home Page Content Updates
> Created: 2025-09-07

## Overview

Update the home page content and design to improve messaging clarity, consolidate redundant sections, and switch from blue/cyan color scheme to emerald/green while maintaining all existing functionality and design patterns.

## User Stories

### Content Optimization
As a site visitor, I want to see clear, concise messaging without redundancy so that I can quickly understand Joey's expertise and services without confusion from duplicate information across sections.

The homepage currently has overlapping content between "Successful projects delivered for" and "Proven Track Record" sections that should be consolidated. Additionally, the hero section mentions experience/companies that are repeated elsewhere.

### Visual Brand Update
As a site visitor, I want to see a cohesive green/emerald color scheme that reflects a fresh, modern brand identity so that the site feels current and professionally aligned with Joey's evolving brand.

The current blue/cyan/turquoise colors throughout the design need to be updated to emerald/green variants while preserving all visual hierarchy and design patterns.

### Content Accuracy
As a site visitor, I want to see current and relevant information about Joey's work and projects so that I understand what he's actively building and his current focus areas.

Several content updates are needed including new hero headline, updated technical skills list, current project information, and asset updates.

## Spec Scope

1. **Hero Section Updates** - Change headline to "Hey, I'm Joey 👋 I Build Software That Works" and update subheading copy without experience/company mentions, plus switch to joey.jpeg converted to WebP
2. **Content Consolidation** - Merge "Successful projects delivered for" and "Proven Track Record" sections to eliminate redundancy
3. **Professional Journey Removal** - Remove entire professional journey section to streamline page content
4. **Technical Expertise Refinement** - Update skills lists across Full-Stack Dev, AI & Automation, and Product Development categories
5. **Current Projects Update** - Replace n8n entry with PHAiTO project information and update Tether emoji to use PNG logo
6. **Color Scheme Migration** - Update all blue/cyan/turquoise references to emerald/green throughout the design
7. **Footer Cleanup** - Remove email address from footer section

## Out of Scope

- Adding new sections or features to the homepage
- Changes to overall page layout or component structure
- Updates to other pages beyond the homepage
- New contact forms or newsletter functionality changes
- SEO or performance optimizations

## Expected Deliverable

1. Homepage displays updated hero headline and refined subheading without redundant company/experience mentions
2. Single consolidated social proof section replacing the two separate overlapping sections
3. Updated technical skills accurately reflecting current expertise areas
4. Current projects section shows PHAiTO with logo instead of n8n
5. All blue/cyan/turquoise colors replaced with emerald/green equivalents throughout the design
6. Hero image uses joey.jpeg converted to WebP format while maintaining circular display
